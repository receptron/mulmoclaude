## まずは「コレクション」画面を開く

画面左の **ランチャー**（アイコンが並んだ列）から **コレクション** を押すか、
ブラウザで [http://localhost:3001/collections](http://localhost:3001/collections) を開きます。

上部に 3 つのタブがあります。

| タブ | 内容 |
|---|---|
| **インストール済み** | 手元にあるコレクションの一覧 |
| **発見** | みんなが公開しているコレクション。ワンクリックで取り込めます（[共有する](share.md#discover)） |
| **マップ** | コレクション同士のつながりを図で表示（つながりがあるときだけ出ます） |

## 作り方 1: 「+ コレクション」ボタンから（いちばん簡単）

**インストール済み** タブの **「+ コレクション」** を押すと、**新しいコレクション** という窓が開きます。
ここに 3 つの入り口があります。

### ガイド付きセットアップ（おすすめ）

**「ガイド付きセットアップ — Claude が何を記録するか質問して作成します」** を押すと、
Claude が「何を記録したいですか？」「どんな項目が要りますか？」と、フォームで質問してきます。
答えていくだけで、設計図ができあがります。**何を書けばいいか分からない人はこれ**を選んでください。

### 自由入力のチャット

**「自由入力のチャット — 作りたいコレクションを自分の言葉で説明」** を押すと、
チャット入力欄に書き出しの文章が入ります。その後ろに、作りたいものを自分の言葉で書き足して送信します。

### サンプルプロンプト

窓の下半分の **サンプルプロンプト** には、すぐ使える例が並んでいます。

| サンプル | できるもの |
|---|---|
| Todo list | ToDo リスト（カンバン、期限、通知つき） |
| Contacts | 連絡先。名刺の写真を添付すると読み取って追加 |
| Reading list | 読みたいものリスト。「読んだ」にチェックするまで通知 |
| Restaurants | お店リスト。行ったあとだけ評価を付けられる |
| Bill Payments | 毎月の支払い。10 日前に通知、翌月分を自動作成 |
| Clients & time | 取引先と作業時間の記録 |
| Invoicing | 請求書 |
| Vocabulary | 単語帳 |
| Lessons | 習い事・レッスンの記録 |
| Stock portfolio | 株のポートフォリオ |

サンプル名は日本語の画面では日本語に訳されて表示されます。カードを押すと、その例文が入力欄に入ります（**すぐには送信されません**）。
「ジャンルの項目も足して」などと書き換えてから送信してかまいません。

## 作り方 2: チャットで頼む

ふだんのチャット画面から、いきなり頼んでもかまいません。コツは **「何を」「どんな項目で」「どう使いたいか」** を書くことです。

**例 1: 読みたいものリスト**

> 読みたいものリストのコレクションを作って。タイトル、URL、「読んだ」チェックボックス。
> 「読んだ」にチェックが付いていない間は、タイトルを通知ベルに出しておいて。

**例 2: 行きたいお店**

> 行きたいお店のコレクションを作って。店名、ジャンル、エリア、Web サイト、電話番号、「行った」チェック、
> 1〜5 の評価、メモ。評価は「行った」にチェックしてからだけ入力できるようにして。

**例 3: 習い事の記録**

> 子どもの習い事の記録を作りたい。習い事の名前、曜日、時間、月謝、先生の連絡先。
> 月謝は円で。カレンダーで見られるようにして。

Claude が作り終えると、チャットの中にコレクションが表示され、
**コレクション** 画面の一覧にも自動で加わります。**再起動は要りません。**

{: .tip }
最初から完璧を目指さなくて大丈夫です。まず小さく作って、使いながら足していくのがいちばんうまくいきます。

## あとから形を変える

コレクションを開いた状態で、ヘッダーの **チャット** ボタンを押して頼むか、ふだんのチャットで
コレクションの名前を出して頼みます。

- 「優先度の項目を足して。高・中・低から選べるように」
- 「メモ欄を複数行にして」
- 「期限の 3 日前に通知して」
- 「カンバンで見られるようにして」
- 「『支払い済みにする』ボタンを付けて」
- 「カードで一覧できるカスタムビューを作って」

すでに入っている記録はそのまま残ります。
