## 作ったコレクションが一覧に出てこない
{: #not-listed }

1. **コレクション** 画面を開き直す（ブラウザの再読み込み）。コレクションの一覧は開くたびに探し直されます
2. それでも出ないときは、設計図が壊れている可能性があります。チャットで

   > 〇〇コレクションが一覧に出ない。schema.json をチェックして直して

   と頼んでください。Claude が設計図を読み込み直し、何が悪いかを調べて直します
3. 手で `schema.json` を書き換えた直後なら、書き間違いを疑ってください（[schema.json のしくみ](schema.md#edit-by-hand)）

{: .note }
**インストール済み** が空のときに「スキーマを含むスキルを Skills ページからスター付けすると、ここに表示されます。」という文が出ますが、
コレクションを作るには **「+ コレクション」** を押せば大丈夫です。

## 記録を追加したのに表に出てこない

- 検索欄や **絞り込み** が効いていないか確認してください（「〇〇 のみ表示中」などのチップが出ていたら押して解除）
- カレンダー表示では、日付が空の記録は **日付なし** に入ります

## カレンダーやカンバンのボタンがない

- **カレンダー** は日付の項目があるときだけ、**カンバン** は選択肢の項目があるときだけ出ます
- 「締め切りの日付を足して」「状態（未着手・進行中・完了）を足してカンバンで見たい」と頼めば出るようになります

## スマホからつながらない

- パソコン側の **リモートホスト** が **オンライン** か確認してください。MulmoClaude を再起動した後は、
  **再接続** が必要なことがあります
- スマホとパソコンで **同じ Google アカウント** でログインしているか確認してください
- パソコンがスリープしているとつながりません。頼んだことは **送信待ち** に入り、パソコンが戻ると送られます

## スマホで記録を追加したい

スマホから直接追加する画面はまだありません。**このコレクションについてチャットを開始** から
「〇〇を追加して」と頼んでください。

## 寄稿がうまくいかない

- パソコンで `gh auth login` を済ませているか確認してください
- Docker のサンドボックスありで動かしている場合は、`.env` に `SANDBOX_MOUNT_CONFIGS=gh` を書いて再起動してください
- 途中で GitHub のユーザー名を聞かれたら、GitHub にログインするときの名前（`@` の後ろ）を答えてください

## 消したコレクションを戻したい

削除の前に、ワークスペースの `archive/` にバックアップが保存されています。
Claude に「昨日消した〇〇コレクションを archive から戻して」と頼んでください。

## それでも解決しないとき

[GitHub の Issues](https://github.com/receptron/mulmoclaude/issues) で質問してください。
