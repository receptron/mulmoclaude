# MulmoClaude ガイド（日本語）

このガイドは、**MulmoClaude をはじめて使う人**が、自分専用のアプリ
（**コレクション**）を作って日々使えるようになるまでを、順番に案内します。
プログラミングの知識は要りません。

## こんなものが作れます

- 📚 読みたい本・記事のリスト（「読んだ」にチェックするまで通知でお知らせ）
- 🍜 行きたいお店・行ったお店（行ったあとだけ評価を付けられる）
- ✅ ToDo リスト（カンバンで進み具合を見る、期限をカレンダーで見る）
- 💴 毎月の支払い（期日の 10 日前にお知らせ、翌月分を自動で作成）
- 🧾 取引先ごとの作業時間と請求書
- 📇 名刺の写真を渡すだけで増えていく連絡先

どれも「〇〇を記録したい」と Claude に話しかけるだけで作れます。
