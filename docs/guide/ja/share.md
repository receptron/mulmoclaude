## 人が作ったコレクションを取り込む（発見）
{: #discover }

**コレクション** 画面の **発見** タブには、公開されているコレクションがカードで並んでいます。
今は公式の置き場所（[receptron/mulmoclaude-collections](https://github.com/receptron/mulmoclaude-collections)）に
あるものが表示されます。映画リスト、カメラのレンズ図鑑、気象庁の天気予報などがあります。

カードに書いてあること:

- タイトルと **作者: 〇〇**
- 項目の数（**{数} フィールド**）、付いているカスタムビュー、**サンプル {数} 件**
- どの置き場所から来たか（**official** などのバッジ）

### 取り込む手順

1. 使いたいカードの **取り込む** を押す（**取り込み中…** と出ます）
2. **取り込み済み · 開く** に変わったら、押すとそのコレクションが開きます
3. **インストール済み** タブにも加わっています

取り込むと、設計図とカスタムビュー、サンプルの記録があなたのワークスペースにコピーされます。
取り込んだあとは**あなたのもの**なので、自由に記録を足したり、Claude に頼んで形を変えたりできます。

{: .note }
同じ名前のコレクションがすでにあるときは、`movies-2` のように別名で取り込まれます（**movies-2 として取り込み**）。
同じものをもう一度取り込むと、設計図だけが新しい版に更新され（**更新済み**）、あなたの記録はそのまま残ります。

### 置き場所を増やす（上級）

会社やコミュニティで独自の置き場所を作った場合は、ワークスペースの
`config/collections-registries.json` に追加すると、発見 タブに一緒に並びます。

```json
[
  {
    "name": "my-team",
    "indexUrl": "https://example.github.io/my-collections/index.json",
    "rawBaseUrl": "https://raw.githubusercontent.com/example/my-collections/main"
  }
]
```

追加したらブラウザを再読み込みしてください。詳しくは開発者向けの
[collection-registries.md](https://github.com/receptron/mulmoclaude/blob/main/docs/collection-registries.md) にあります。

## 自分のコレクションを公開する（寄稿）
{: #contribute }

よくできたコレクションは、公式の置き場所に公開して、ほかの人の **発見** タブに並べられます。

### 必要なもの

- **GitHub のアカウント**
- パソコンに **GitHub CLI（`gh`）** が入っていて、ログイン済みであること
  （ターミナルで `gh auth login` を一度実行）

{: .warning }
MulmoClaude を **Docker のサンドボックスあり**で使っている場合、Claude はそのままでは GitHub にログインできません。
`.env` に `SANDBOX_MOUNT_CONFIGS=gh` を書いて MulmoClaude を起動し直すと、パソコン側の `gh` のログインを使えるようになります。

### 手順

1. **コレクション** 画面の **インストール済み** タブで、公開したいコレクションのカードにある
   **共有アイコン（寄稿）** を押す
2. 「『〇〇』コレクションをシェアしますか？…GitHub PR を作成します。」と確認されるので **寄稿** を押す
3. 新しいチャットが始まり、Claude が作業を進めます。途中で次のことを聞かれます
   - **GitHub のユーザー名**（公開したときの作者名になります）
   - 最後に **PR（公開の申請）を出してよいか**
4. 公式の置き場所の管理者が確認して取り込むと、みんなの **発見** タブに表示されます

### あなたの記録は公開されません

公開されるのは **設計図とカスタムビュー** です。サンプルとして添える記録は、あなたの本物の記録ではなく、
**Claude が設計図から作った架空のデータ（3〜5 件）** です。
パスワードや API キーのようなものが含まれていると、公開の審査で自動的に止められます。

## スマホで使う
{: #phone }

パソコンで動いている MulmoClaude に、外出先のスマホからつなげます。
ポートの開放などの難しい設定は要りません。**同じ Google アカウントでログインするだけ**です。

### パソコン側の準備

1. MulmoClaude の画面上部にある **リモートホスト** ボタン（スマホとパソコンの形のアイコン）を押す
2. **Google でサインイン** を押してログイン
3. **リモートホスト: オンライン** になり、ボタンが緑になれば準備完了

{: .note }
MulmoClaude を再起動すると、つなぎ直しが必要なことがあります。切れたときは画面に
**リモートホストが切断されました** と出るので、**再接続** を押してください。

### スマホ側

1. スマホのブラウザで **[mulmoserver.web.app](https://mulmoserver.web.app)** を開く
   （パソコンの **リモートホスト** の窓に出る **QR コード**をスマホのカメラで読んでも開けます）
2. **Google アカウントでサインイン**（パソコンと同じアカウント）
3. ホーム画面の **ホスト** から **MulmoClaude** を押す
4. **コレクション** を開くと、パソコンのコレクションが並んでいます

### スマホでできること・できないこと

| できること | どうやって |
|---|---|
| コレクションと記録を見る | コレクションを開くだけ。カードで一覧、**もっと読み込む** で続きを表示 |
| スマホ向けの見た目で見る | パソコンで作った **スマホビュー** を **ビューを切り替え** から選ぶ（下記） |
| 記録を直す・消す | スマホビューが「直してよい」と決めた項目だけ |
| Claude に頼む | **このコレクションについてチャットを開始** / **この項目についてチャットを開始**。写真も添付できる |
| パソコンが止まっていても頼む | 頼んだ内容は **送信待ち** になり、パソコンが戻ると自動で送られる（7 日間） |

{: .warning }
スマホから **新しい記録を直接追加する画面はまだありません**。追加したいときは、
チャットで「〇〇を追加して」と頼んでください（写真を添付すれば読み取って追加してもらえます）。

### スマホビューを作る

スマホで使いやすい見た目は、パソコンで作ります。

1. パソコンでコレクションを開き、ツールバーの **+**（**ビューを追加**）→ **スマホビュー**
2. チャットで、スマホでどう使いたいかを伝える

   > スマホで買い物中に見るので、まだ買っていないものだけを大きな文字で。タップで「買った」にできるように。

3. パソコンの画面に、スマホの大きさでプレビューが出ます

スマホで直してよい項目や、ボタンを押したらすぐ Claude に頼むか（下書きにするか）も、ここで伝えれば設定してもらえます。

{: .note }
スマホにつながるのは **あなた自身の Google アカウントだけ** です。ほかの人のアカウントからは、あなたのパソコンには届きません。

## 人に入力してもらう
{: #others }

**現在の MulmoClaude には、コレクションを他の人に公開して入力してもらう機能（共有リンクや公開フォーム）はありません。**
スマホからの接続も、あなた自身の Google アカウントに限られます。

代わりに、次の方法があります。

| 方法 | 向いている場面 | 注意 |
|---|---|---|
| **メッセージアプリ経由で頼んでもらう** — Telegram や LINE などを MulmoClaude につなぎ（[MulmoBridge ガイド](https://github.com/receptron/mulmoclaude/blob/main/docs/mulmobridge-guide.md)）、家族に「〇〇を追加して」と送ってもらう | 家族など、ごく親しい人 | 許可した人は **Claude そのもの** と話せます。特定のコレクションだけに限る仕組みではありません |
| **MulmoTerminal の共有アプリを使う** — 兄弟アプリの [MulmoTerminal](https://www.mulmoterminal.com/) では、アンケート・申込表・予約ページのような「複数人が入力するアプリ」を作り、リンクを配って使ってもらえます。あなたのパソコンを閉じても動き続けます | イベントの申し込み、チームでの記録 | MulmoClaude とは別のアプリで、MulmoClaude のコレクションをそのまま公開するものではありません。[共有アプリの説明（英語）](https://www.mulmoterminal.com/guide/en/shared-apps.html) |
| **取り込み・ファイルで仕組みを渡す** — 相手にも MulmoClaude を使ってもらい、同じコレクションを持ってもらう | 同じ記録のしかたを広めたい | 記録そのものは共有されず、それぞれの手元に貯まります |

## ファイルで渡す
{: #files }

コレクションは普通のファイルなので、フォルダごと渡せば相手も使えます。

### 渡す側

ワークスペース（`~/mulmoclaude`）の中の、次のフォルダをコピーします。

| 渡すもの | 場所 | 必要？ |
|---|---|---|
| コレクション本体（設計図・説明書・ビュー） | `.claude/skills/<slug>/`（`SKILL.md`、`schema.json`、`views/`、`templates/`） | 必須 |
| 記録 | 設計図の `dataPath` に書いてあるフォルダ（ふつうは `data/<名前>/items/`） | 記録も渡したいときだけ |

{: .tip }
カスタムビューが `.claude/skills/<slug>/` に入っていないときは、`data/skills/<slug>/views/` にあります。
一緒にコピーしてください。迷ったら Claude に「restaurants コレクションを人に渡せるように 1 つのフォルダにまとめて」と頼むのが確実です。

### 受け取る側

1. 受け取ったフォルダを、自分のワークスペースの `.claude/skills/<slug>/` に置く
2. 記録も受け取ったなら、設計図の `dataPath` と同じ場所に置く
3. **コレクション** 画面を開き直す（再起動は不要です）

または、受け取ったフォルダを Claude に見せて「これをコレクションとして取り込んで」と頼んでもかまいません。

{: .warning }
記録には個人情報が含まれていることがあります。渡す前に中身を確認してください。
画像やファイルの項目は、あなたのパソコン上の場所を指しているので、画像そのものも一緒に渡さないと相手の画面では表示されません。
