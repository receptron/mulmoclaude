## コレクションを開く

**コレクション** 画面の **インストール済み** タブで、使いたいコレクションのカードを押します。
上の **コレクションを検索…** で名前から探せます。

開いた画面は、上から次の 3 段になっています。

| 段 | 並んでいるもの |
|---|---|
| **ヘッダー** | ← 戻る、★（固定）、タイトル、**チャット**、**関連**、**追加**、**コレクションを削除** |
| **ツールバー** | **レコードを検索…**、**絞り込み**、**テーブル / カレンダー / カンバン**、**+**（ビューを追加）、**⚙**（コレクション設定） |
| **本体** | 表・カレンダー・カンバン、またはカスタムビュー |

## 記録を追加する

いちばん簡単なのは、ヘッダーの **追加** ボタンです。**新規追加** の入力欄が開くので、
埋めて **保存** を押します。

- 選択肢の項目は **選択…** から選びます
- 表の形の項目（明細など）は **行を追加** で行を増やします
- 項目によっては、ほかの項目の値しだいで表示されます（例: 「行った」にチェックすると「評価」が出る）

### Claude に追加してもらう

入力が面倒なときは、Claude に頼めます。

> お店リストに「ラーメン太郎」を追加して。新宿、ラーメン、まだ行ってない。

> この名刺を連絡先に追加して（写真を添付）

> このレシートの内容を支払いに登録して（写真を添付）

Claude が追加し終えると、チャットの中に結果が表示されます。

## 記録を見る・直す・消す

表の行を押すと、右側に詳細が開きます。

| ボタン | すること |
|---|---|
| **編集** | 内容を書き換える。終わったら **保存**、やめるなら **キャンセル** |
| **削除** | 記録を消す（「この項目を削除しますか？元に戻せません。」と確認されます） |
| 設計図で決めたボタン | 例: 「支払い済みにする」「請求書を作る」 |

詳細の下にある **このレコードについてチャット** に書くと、その記録について Claude に頼めます。
例: 「この請求書を PDF にして」「このお店の営業時間を調べて追記して」。

{: .tip }
チェックボックスや選択肢の項目は、詳細を開かなくても**表のセルを直接押して**変えられます。

## 見方を切り替える

ツールバーの **テーブル / カレンダー / カンバン** で切り替えます。

| 見方 | いつ出るか | できること |
|---|---|---|
| **テーブル** | いつでも | 列の見出しを押すと並べ替え（次に開いたときも覚えています） |
| **カレンダー** | 日付の項目があるとき | 月ごとに表示。**今日**、**前の月**、**次の月**。日付を押すとその日の一覧、**+** でその日に追加 |
| **カンバン** | 選択肢の項目があるとき | カードを列から列へドラッグすると、その項目の値が変わる。値が空のものは **未分類** の列に |

日付の項目や選択肢の項目が複数あるときは、**カレンダーの日付フィールド** / **カンバンのグループフィールド** で
どれを使うか選べます。

## つながっているコレクションを見る

「請求書」が「取引先」を参照している、のようにコレクション同士がつながっているときは、
ヘッダーの **関連** から相手のコレクションへ移れます。全体のつながりは、コレクション画面の **マップ** タブで図として見られます。

## 探す・絞り込む

- **レコードを検索…** に文字を入れると、合う記録だけが表示されます（「20 件中 3 件を表示」のように件数も出ます）
- 設計図に「絞り込み用の条件」があると **絞り込み** メニューが出ます。
  押すたびに「〇〇 を非表示中」→「〇〇 のみ表示中」→ 解除、と切り替わります

## Claude に頼む

ヘッダーの **チャット** を押すと **チャットを開始** の窓が開きます。
**このコレクションで行いたいことを入力してください…** に書いて **チャットを開始** を押すと、
このコレクションのことを分かった状態の Claude と会話が始まります。

頼めることの例:

- 「今月の支払いの合計を出して」
- 「まだ行っていないお店を、エリアごとにまとめて」
- 「期限を過ぎた ToDo を一覧にして」
- 「このリストを CSV にして」
- 「この 3 件をまとめて完了にして」

## カスタムビュー（自分だけの見た目）

表やカンバンでは物足りないときは、見た目そのものを作ってもらえます。

1. ツールバーの **+**（**ビューを追加**）を押す
2. **カスタムビュー** を選ぶ（スマホ用なら **スマホビュー**。[スマホで使う](share.md#phone)）
3. 開いたチャットで、どんな見た目にしたいかを伝える

例: 「映画をポスターのタイルで並べて」「今週の予定を時間割のように」「家計をグラフで」。

できたビューはツールバーにボタンとして並びます。要らなくなったら **⚙（コレクション設定）** から消せます。

## よく使うコレクションをすぐ開けるようにする

コレクションのヘッダーにある **★** を押すと、**ランチャーに固定** されます。
ランチャーからワンクリックで開けるほか、**ダッシュボード** 画面にお気に入りとして並びます。
外すときはもう一度 ★ を押します（**ランチャーから外す**）。

## 通知（ベル）

「終わっていないものを通知する」「期日の N 日前に知らせる」ように作ったコレクションは、
画面上部の **ベル** に表示されます。完了にすると消えます。

## コレクションを削除する

ヘッダーの **コレクションを削除** で消せます。
**削除前に復元可能なバックアップが保存されます**（ワークスペースの `archive/` に入ります）。
