MulmoClaude はじめての準備

この手順書では、MulmoClaude を使う前に、Mac に Node.js と Claude Code を入れる手順を説明します。Claude Code にメッセージを送るところまで、上から順に進めてください。目安は15〜20分です。

MulmoClaude 自体のインストールは、別の手順書で説明します。

用意するものは、インターネットにつながった Mac、Claude の有料プラン（Pro・Max・Team・Enterprise）のアカウント、Mac のログインパスワードです。無料プランでは Claude Code を使えません。パスワードは途中で1回聞かれます。

画面の図はすべてイメージです。実際の表示とは少し違うことがあります。

  • ステップ 1　ターミナルを開く
  • ステップ 2　Node.js を入れる
  • ステップ 3　Claude Code を入れる
  • ステップ 4　ログインして話しかける
  • うまくいかないとき

ステップ 1ターミナルを開く

ターミナルは、文字を打ち込んで Mac を操作するアプリです。Claude Code はターミナルの中で動きます。

1command キーとスペースキーを押す

⌘ の印が付いた command キーを押したまま、スペースキーを押します。

検索窓が出ないとき

Finder →「アプリケーション」→「ユーティリティ」と開き、「ターミナル」をダブルクリックします。

2ターミナルを検索する

検索窓に「ターミナル」と打ち、return キー（Enter と同じ）を押します。

3ターミナルの窓を確認する

この画面が出れば準備完了です。打った文字は、点滅する四角の位置に出ます。

次からすぐ開けるようにしたいとき

Dock のターミナルのアイコンを右クリックし、「オプション」→「Dock に追加」を選びます。

4コマンドを貼り付ける

灰色の枠の右にある「コピー」を押し、ターミナルをクリックして command+V で貼り付け、return を押します。「%」より左は Mac が表示している部分なので、打つ必要はありません。

メモreturn を押したあと、何も表示されずに次の行に「%」が出るだけのこともあります。それで正常です。

ステップ 2Node.js を入れる

MulmoClaude を動かすために、Node.js を入れます。

1Node.js が入っているか確かめる

次を貼り付けて return を押します。「command not found」と出たら次へ進みます。

node -v
v22.19.0 のような数字が出たとき

Node.js はすでに入っています。v22.19.0 以上ならステップ3へ進み、古ければこのまま新しいものを入れてください。

2インストーラーをダウンロードする

ブラウザで https://nodejs.org/ja/download を開き、LTS の「macOS インストーラー（.pkg）」をダウンロードします。

3インストーラーを進める

ダウンロードした node-○○.pkg をダブルクリックし、右下の青いボタン（「続ける」「同意する」「インストール」）を順に押して進めます。

4Mac のパスワードを入れる

Mac にログインするときのパスワードを入れ、インストールが終わったら「閉じる」を押します。

5Node.js をもう一度確かめる

ターミナルを command+Q で終了して開き直し、次を貼り付けて return を押します。開き直さないと、新しく入れた Node.js が見つかりません。

node -v
確認v で始まる数字が出れば成功です。数字は入れた時期によって変わります。

ステップ 3Claude Code を入れる

1Claude Code をインストールする

次のコマンドを貼り付けて return を押し、1〜2分待ちます。Claude Code の公式のセットアップ手順と同じコマンドです。

curl -fsSL https://claude.ai/install.sh | bash
確認「Claude Code successfully installed!」と出れば成功です。
黄色い Setup notes が出たとき

画面に出た行と同じコマンドを、下の枠の「コピー」でコピーします。

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

インストールのコマンドを実行したのと同じターミナルで、一番下の「%」の後ろをクリックします。command+V で貼り付け、return を押します。

何も表示されず、次の行に「%」が出れば終わりです。

注意「curl: (28)」と出て止まったら、この手順書の最後にある「curl: (28) と出てインストールが止まったとき」へ進んでください。

2Claude Code が入ったか確かめる

ターミナルを開き直し、次を貼り付けて return を押します。

claude --version
確認数字が出れば成功です。

ステップ 4ログインして話しかける

1Claude Code を起動する

次を貼り付けて return を押します。画面の色を聞かれたら、そのまま return を押します。

claude

2ログイン方法を選ぶ

「1. Claude account with subscription」が選ばれた状態のまま return を押します。

3ブラウザで承認する

開いたブラウザで普段使っている Claude のアカウントにログインし、「承認（Authorize）」を押します。

ブラウザが開かないとき

ターミナルに出た https:// で始まる長い URL をコピーし、ブラウザに貼り付けて開きます。

4ターミナルに戻る

「Login successful」と出たら return を押します。続けて出る説明の画面も、return で進めます。

5フォルダの確認に答える

「Do you trust the files in this folder?」が出たら、「1. Yes, proceed」を選びます。Claude Code にこのフォルダの中身を読ませてよいか、という確認です。

6日本語で話しかける

「何ができるか教えて」など、質問や頼みごとを日本語で打って return を押します。

確認返事が表示されれば完了です。

終わるときは /exit と打って return を押します。次からは claude と打つだけで始まります。

うまくいかないとき

画面に出た文字意味と対処
command not found: nodeNode.js が入っていないか、ターミナルを開き直していない可能性があります。開き直してステップ2の確認をやり直し、数字が出なければステップ2から進めてください。
command not found: claudeインストール直後なら、ターミナルを開き直してください。それでも出る場合は、ステップ3の黄色い注意に表示された1行を貼っていない可能性があります。
curl: (28)／Failed to connect／timed outターミナルからインターネットにつながっていません。下の「curl: (28) と出てインストールが止まったとき」へ進んでください。
certificate を含むエラー会社のネットワークが通信を検査しているときに出ることがあります。自分で設定を変えず、情報システム担当に画面を見せてください。
その他下の診断用コマンドで原因を調べてください。それでも分からなければ command+shift+4 で画面を撮り、詳しい人に見せてください。

診断用コマンド:

claude doctor
curl: (28) と出てインストールが止まったとき

会社の Mac は、「プロキシ」という中継サーバーを通してインターネットにつながる設定になっていることがあります。ブラウザはこの設定を自動で使うので、claude.ai が開けます。ターミナルは自動では使わないため、接続できずに止まることがあります。

確かめ方

1ブラウザで claude.ai を開く

ブラウザで https://claude.ai を開きます。開けなければ、会社のネットワークで claude.ai への接続が制限されている可能性があるため、管理者に相談してください。開けたら、次へ進みます。

2プロキシの設定を表示する

ターミナルに次を貼り付け、return を押します。

scutil --proxy
  • 「HTTPSEnable : 1」と「HTTPSProxy」「HTTPSPort」が出たら、プロキシを使う設定です。この画面を撮り、管理者への連絡に添えてください。
  • 「ProxyAutoConfigEnable : 1」が出たら、自動設定ファイル（PAC）を使う方式です。これも画面を撮って添えてください。
  • どちらも出なければ、プロキシ以外の理由も考えられます。そのまま管理者に相談してください。
注意Mac の「システム設定」でプロキシの設定を外したり、書き換えたりしないでください。スマホのテザリングで会社のネットワークを迂回する場合も、先に会社の規程を確認してください。

管理者に伝えること

撮った画面を添えて、管理者（情報システム担当）に次のことを伝えてください。

  • 業務で、ターミナルから使う AI ツールの Claude Code（Anthropic 社）と、それを使って動くアプリ MulmoClaude を使いたいこと。社内で使ってよいか確認したいこと。
  • 社内ネットワークではブラウザで claude.ai を開ける一方、ターミナルからの接続は「curl: (28)」でタイムアウトすること。ターミナルの通信が会社のプロキシを通っていないのが原因と考えていること。
  • 添えた画面が scutil --proxy の結果であること。
  • ターミナルの通信もプロキシを通るよう、設定方法を教えてもらうか、設定してもらいたいこと。または、Claude Code をインストールして使える状態にしてもらいたいこと。
  • 主な通信先は、claude.ai（インストール用スクリプトとログイン）、downloads.claude.ai（Claude Code 本体のダウンロード）、api.anthropic.com（Claude Code を使うときの通信）、registry.npmjs.org（MulmoClaude のダウンロードと更新の確認）であること。正式な一覧は Anthropic 社の公式ドキュメント（Claude Code のネットワーク設定）にあること。
  • 会社が通信を検査している場合は、ターミナルに設定する社内の証明書が必要なこと。

管理者の方向けの技術補足

scutil --proxy の HTTPSProxy／HTTPSPort を確認し、ホストとポートを置き換えてプロキシを設定してから、インストールを実行します。

export https_proxy=http://<ホスト>:<ポート>
curl -fsSL https://claude.ai/install.sh | bash

設定を継続して使う場合は、~/.zshrc に https_proxy と no_proxy=localhost,127.0.0.1,.local を追記します。PAC を使っている場合、curl は PAC を直接読めないため、PAC 内の該当する PROXY host:port を指定します。TLS 検査がある場合は、必要に応じて社内ルート証明書を NODE_EXTRA_CA_CERTS で指定します。

通信先の正式な一覧は、Claude Code のネットワーク設定を参照してください。
