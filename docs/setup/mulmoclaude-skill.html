面倒な仕事を MulmoClaude に任せる

この手順書は、1本目のClaude Code の準備と2本目のMulmoClaude のインストールを済ませた人向けです。

毎回同じ手順でしている仕事は、MulmoClaude に任せられます。ただ、いきなり頼むのではなく、先に自分の仕事を整理します。

前半では、まず AI に仕事のやり方を覚えさせる「スキル」とは何かを説明し、次に仕事を「書き出す・分解する・小さく作る」の順で整理する方法を説明します。

後半のステップでは、実際に MulmoClaude に頼みます。ステップ1では、請求書から支払い伝票の PDF を作る手順をスキルとして覚えさせます。ステップ2では、毎朝ニュースを集める作業を、決まった時刻に自動で動かします。

スキルとは

スキルは、仕事のやり方を順番に書いた手順書です。AI はそれを読んで、そのとおりに仕事をします。一度作れば、毎回同じ説明をし直さずに済みます。

手順書は SKILL.md というファイルです。中身は、たとえば次のような文章です（一部）。

# 支払い伝票を作る

## 手順
1. 請求書を読み込む
2. 請求書から項目を抜き出す
3. 足りない情報があれば、聞く
4. 見本と同じ様式に埋めて、PDF で出す

「#」は見出しの印です。印が少し付いているだけのふつうの文章なので、人も AI もそのまま読めます。AI が何をするつもりか、自分の目で確かめられます。

手順書を自分で書く必要はありません。仕事の手順を AI に伝えれば、AI が作ってくれます。直したいところも、チャットで伝えれば書き直してくれます。

MulmoClaude で作った手順書は、作業用フォルダ（~/mulmoclaude）に保存されます。会話を閉じても残り、新しい会話でも使えます。中身は「スキル」の画面で読めます。

任せる前に考えること

AI に頼む前に、自分の仕事を次の3つの順で整理します。整理しておくと頼む文が書きやすくなり、思った物ができやすくなります。

1. 書き出す

今やっている仕事を、最初から最後まで順番に書き出します。ファイルを開く、金額を確かめる、足りない情報を人に聞くなど、ふだん意識せずにしている小さな作業も書きます。何を見て作業するか（請求書や様式など）、途中で何を判断するかも書いてください。

AI はあなたの仕事のやり方を知りません。頭の中にあるだけの手順は伝わらないので、書き出した手順をステップ1の「頼む文を書く」で使います。うまく書けないときは、AI に「質問しながら、私の仕事の手順を書き出すのを手伝って」と頼んでもかまいません。

2. 分解する

まず、何ができたら完了かを決めます。今している作業の形にとらわれずに考えてください。「経理システムに入力する」は作業の一つです。その入力は何のためかを問い直し、「結局、何が出てくれば困らないか」まで掘り下げます。

会社のシステムに入力しているなら、入力したあとにシステムが何を出しているかを見ます。支払い伝票なら、システムが刷る、様式の決まった伝票です。AI には入力の作業をまねさせるのではなく、その様式の PDF を作らせます。

システムへの入力が要るかどうかは、伝票を受け取る人や、その後の仕事を見て確かめます。

  • システムが刷る伝票があれば仕事が回るなら、AI が作った PDF で完了です。システムへの入力は要りません。
  • システムにも記録を残す必要があるなら、入力は残ります。その場合は、人が入力しやすい形は何かを考えて、AI に作らせる物を決めます。たとえば、入力画面と同じ順に項目を並べた一覧なら、上から写すだけで入力できます。

完了の定義が決まったら、それを作るための作業に細かく分解し、作業ごとに AI に任せるか人がやるかを決めます。パスワードが要る作業は人がやります。AI にパスワードを渡すと、そのシステムであなたができることを何でもできるようになるからです（下の「AI に任せないこと」を参照）。

3. 小さく作る

自動化は、まず小さい単位で1つ作り、動作が確認できたらその範囲を広げます。最初から全部を作る必要はありません。一度にたくさん頼むと、思った物にならなかったときに、どこがずれたのか分かりにくく、直しにくいからです。1つずつなら、見本や結果と比べて、ずれた所をすぐ直せます。

たとえば、支払い伝票を作る仕事なら、できあがる物は PDF です。最初は「請求書を読む→項目を抜き出す→足りない情報を聞く→様式に埋めて PDF にする」という流れを作ります。領収書（立て替えた経費の精算）など、別の書類から作る方法はあとで足します。

また、たとえば、毎朝ニュースから情報収集する仕事なら、できあがる物は毎朝のニュースの一覧です。最初はきのうから今朝までのニュースを集める作業だけを作り、1回動かして確かめてから毎朝7時に動かし、残りの2つの作業はあとで1つずつ足します。一度に増やすと、どこがずれたのか分かりにくくなるからです。

ステップ 1スキルを作る（支払い伝票）

ここでは、請求書を渡すだけで支払い伝票の PDF ができるスキルを作ります。

1見本を用意する

空欄の支払い伝票の様式を PDF で1枚、Mac に保存しておきます。これができあがる物の見本になります。

2新しい会話を始める

MulmoClaude の画面左上にある「＋」を押します。

3頼む文を書く

入力欄に次の文を書きます。「〇〇」は自分の仕事に置き換えてください。

私は〇〇の仕事をしています。
添付のような支払い伝票を毎回作るのが面倒なので、請求書から自動で PDF を作る仕組みを作ってください。
1. 請求書を読み込む
2. 請求書から項目を抜き出す
3. 支払い伝票に必要な情報が足りなければ、私に聞く
4. 添付と同じ様式に情報を埋めて、PDF で出す

頼む文は「自分の役割→面倒なこと→材料→手順→できあがる物」の順に書くと伝わります。

4見本を添付して送る

入力欄のクリップのアイコンから、「見本を用意する」で保存した PDF を選んで送ります。作り終わるまで数分かかります。

5できた手順書を確かめる

見本を送ってスキルができたら、入力欄に「作ったスキルを見せて」と送ります。画面右に開く「スキル」の画面で、左の一覧から作ったスキルを選び、右に表示される手順書（SKILL.md）が「頼む文を書く」で書いた手順どおりか確かめ、違うところはチャットで直してもらいます。

6請求書を渡して試す

新しい会話を始め、請求書の PDF を添付して「この請求書で支払い伝票を作って」と送ります。足りない情報を AI に聞かれたら答えます。

確認見本と同じ様式の PDF ができれば成功です。

7見本と比べて直す

できた PDF を見本と比べます。違うところがあれば、command＋shift＋4 で範囲を選んでデスクトップに保存した画面の写真を入力欄にドラッグし、「金額の『円』は要らない」のように直したい点を書いて送ります。

入口が2つ以上あるとき

請求書から始まる場合と、立て替えた経費の領収書から始まる場合のように入口が複数あっても、まず1つで作ります。動作が確認できたら「〇〇から始まる場合も足して」と頼みます。

ステップ 2毎朝、自動で動かす（ニュース集め）

ここでは、知りたい話題のニュースを MulmoClaude が毎朝決まった時刻に自動で集め、一覧にするようにします。

1まず1回やらせる

「〇〇に関する、きのうから今朝までのニュースを集めて一覧にして」と送ります。「〇〇」には知りたい話題を入れます。

2結果を確かめる

欲しい一覧になっているかを見ます。途中で止まったら「なぜ止まったか」「別のやり方はあるか」と聞き、そのうえで本当にそこまで要るかを決め直します。全部取れなくても、目的には足りることがあります。

3毎朝やるように頼む

結果を確かめたら、「これを毎朝7時にやって」と送ります。

注意決まった時刻に動くのは、MulmoClaude が起動している間だけです。ターミナルの窓を閉じず、Mac をスリープさせないでください。
確認返事に登録した時刻が出れば完了です。
深掘りや週のまとめもしたいとき

一度に頼まず、別の作業として1つずつ足します。たとえば、集めたニュースから深掘りする記事を挙げる作業や、週末にその週の変化をまとめる作業です。1つずつなら、見本や結果と比べて、ずれた所をすぐ直せます。

AI に任せないこと

会社のシステムへの入力やネットバンキングなど、パスワードを入れる操作は AI にさせないでください。パスワードを渡すのは合鍵を渡すのと同じで、そのシステムであなたができることを何でもできるようになります。

  • AI が指示を取り違えたり、読んだウェブページの文に引っぱられたりすると、送金・削除・誤入力など、取り消せない操作をしてしまうことがあります。
  • チャットに書いたパスワードは、MulmoClaude の作業用フォルダ（~/mulmoclaude/conversations）の会話の記録に残ります。会話の文は Claude の提供元（Anthropic）にも送られます。AI がうまくいかず別のやり方を探すうちに、見知らぬサイトへ入力してしまうこともあります。
  • 会社のシステムなら、パスワードを人に渡してよいか、社内の規程も確かめてください。

そうした仕事を任せたいときは、先に仕事のやり方を作り直し、鍵を渡さなくて済む形にします。

AI に別のやり方を探させるときは、2本目のステップ1で説明した Docker のサンドボックスの中で動かします。中の AI が読み書きできるのは、MulmoClaude の作業用フォルダ（~/mulmoclaude）と Claude Code の設定（~/.claude）だけです。Mac のほかのファイルは見えません。ただし、インターネットは使えます。サンドボックスの中でも、AI にパスワードは渡さないでください。

うまくいかないとき

困ったことどうするか
動いているか分からない「今どこまで進んだ？」と聞きます。
思っていた物と違う見本と違うところを具体的に伝えます。画面の写真を貼ると伝わりやすくなります。
決まった時刻に動かなかったその時刻に MulmoClaude が起動していたか確かめます。
画像を作れない画像の生成には、Gemini の API キーが別に要ります。

画面の図はイメージです。実際の表示とは少し違うことがあります。
